# valorant-instalock

## CASTELLANO

**Junior - Valorant Instalock** es una herramienta ligera y profesional diseñada para asegurar tu agente favorito en VALORANT de forma automática y ultra rápida. Olvídate de perder tu main por falta de reflejos.

## 🚀 Características Principales

* ⚡ **Instalock de Alta Velocidad:** Bloquea al agente en milisegundos mediante la API de Riot.
* 🔄 **Detección Inteligente de Ciclos:** Reconoce automáticamente si estás en el Menú, buscando partida o jugando.
* 🤖 **Notificaciones de Telegram:** Recibe alertas en tu móvil cuando encuentres partida o bloquees al agente.
* ♻️ **Auto-Reset:** El script se reactiva solo al terminar cada partida.
* 🎨 **Interfaz Estética:** Dashboard minimalista basado en consola.


## ENGLISH

**Junior Instalock** is a lightweight, professional tool designed to secure your favorite agent in VALORANT automatically and ultra-fast. Stop losing your main due to slow reaction times.



## 🚀 Key Features

* ⚡ **High-Speed Instalock:** Locks your agent in milliseconds via the Riot API.
* 🔄 **Smart Cycle Detection:** Automatically recognizes if you are in the Menu, Queueing, or In-Game.
* 🤖 **Telegram Notifications:** Receive remote alerts on your phone when a match is found or an agent is locked.
* ♻️ **Auto-Reset:** The script reactivates itself after every match. No manual intervention needed!
* 🎨 **Clean Aesthetic:** Minimalist console-based dashboard.
